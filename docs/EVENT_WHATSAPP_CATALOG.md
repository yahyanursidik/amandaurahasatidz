# Komunikasi WhatsApp dan katalog event

- **Admin → Event & Daurah** (`/admin/events`) memakai katalog server-side, 12 event per halaman, pencarian nama/kode/lokasi, filter status, ringkasan status dan urutan tanggal terbaru. Katalog hanya mengirim URL poster ringan; poster data-URI berukuran besar diganti poster bawaan dalam daftar. Poster asli tetap tersedia di detail event.
- Pada setiap baris event, **WhatsApp** menyediakan template **Undangan** (informasi umum, tanpa token pribadi) dan **Pendaftaran reguler** (tautan `/register` hanya ketika pendaftaran reguler dibuka). Nomor tujuan boleh dikosongkan untuk memilih kontak di WhatsApp, atau diisi 08/+62. Pesan bisa disunting dan disalin sebelum membuka `wa.me`. Event draft/telah dibatalkan tidak bisa dibagikan.
- Untuk **undangan lembaga yang memakai token/kode khusus**, buka **Event → Undangan**, buat tautan khusus lembaga, lalu gunakan aksi **WhatsApp/Email** pada undangan itu. Tautan pribadi tidak dicampurkan ke template umum katalog.
- **Event → Peserta** sudah memiliki panel **Hubungi** yang membuka WhatsApp atau email dari profil peserta, kini dengan template undangan atau reguler sebagai opsi awal. Panel serupa tersedia di **Admin → Data Asatidz** untuk kontak lintas event, memakai template sapaan umum agar tidak salah mengklaim seseorang sudah mendaftar. Panel peserta di portal panitia juga memakai template sesuai jalur pendaftaran.
- Aksi WhatsApp membuka aplikasi tujuan dengan teks siap kirim; `mailto:` membuka aplikasi email perangkat. Keduanya tidak membuktikan pengiriman selesai dan tidak mengirim otomatis dari server. Nomor/ email yang belum valid harus diperbaiki di profil dahulu.
