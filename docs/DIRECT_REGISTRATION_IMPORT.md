# Pendaftaran reguler langsung dan impor peserta lintas event

- Landing event reguler hanya memuat informasi program dan formulir reguler. Informasi jalur undangan tidak ditampilkan di landing/formulir publik; undangan memakai tautan/kode pribadi pada halaman terpisah.
- Formulir reguler menerima nama, email pribadi, WhatsApp, alamat opsional, dan anggota rombongan opsional dalam satu pengiriman. Tidak ada tahap OTP pendaftaran. Data tetap masuk status `PENDING_REVIEW`, setiap email unik per rombongan, satu profil hanya sekali per event, dan API menerapkan batas percobaan per IP. Aktivasi akun portal tetap memerlukan verifikasi email terpisah.
- Impor CSV melakukan preview terlebih dahulu. Profil yang cocok berdasarkan email/nomor (termasuk nomor lama berformat `08…`, `+62…`, dan tanda pemisah) digunakan ulang; nama/kontak yang tidak cocok atau beberapa profil kandidat ditolak untuk tinjauan manual. Preview menunjukkan jumlah event **sebelumnya yang disetujui**. Jika baris saat ini berstatus `APPROVED`, jumlah partisipasi disetujui pada detail asatidz bertambah setelah impor. Persetujuan berarti partisipasi tercatat, bukan bukti presensi.
- Impor diproses dalam kelompok 20 baris; indikator memperlihatkan persentase/baris yang selesai setelah setiap respons API. Kode peserta hasil preview dikirim ke tiap kelompok agar unik; baris yang telah diimpor dilewati saat percobaan ulang. Jika kelompok gagal, simpan file CSV yang sama dan ulangi impor setelah masalah diperbaiki.
- Navigasi `/admin/ustadz` menjaga pencarian dan filter ketika berpindah halaman. Mengubah pencarian/filter memulai kembali dari halaman pertama.
