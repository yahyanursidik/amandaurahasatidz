# Gate cepat panitia

- Halaman `/gate` atau `/gate/:eventSlug` terbuka melalui URL singkat namun **memerlukan login panitia** dan penugasan dengan izin `attendance.record`. Rute `/check-in` lama sekarang mengarahkan pada halaman operasional yang sama, bukan halaman statis yang menyatakan check-in selalu terbuka.
- Petugas memilih event penugasan dan hari/sesi yang sedang membuka check-in, kemudian memakai QR lewat kamera, mengetik kode peserta, atau mencari nama. Pencarian hanya menampilkan paling banyak 12 kandidat per event dan memerlukan setidaknya dua karakter; petugas memilih orang yang tepat sebelum mencatat. Kamera perlu izin perangkat dan `BarcodeDetector`; bila browser tidak mendukung, kode/nama tetap tersedia.
- Token QR peserta ditandatangani dengan event ID dan versi rotasi. Kode peserta unik per event, sedangkan pencarian nama tidak langsung mencatat presensi: selalu diarahkan ke kode peserta terpilih. Server menolak status belum disetujui, event lain, unit tertutup, dan duplikat check-in pada unit yang sama.
- Admin event memiliki tabel peserta yang dipaginasi; header kolom tetap berbentuk tabel pada semua layar dan tabel panjang dapat digeser horizontal pada ponsel.
